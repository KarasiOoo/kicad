# KiCad PCB Projects

Repozytorium projektów płytek PCB rysowanych w **KiCad**.

## Struktura

```
KiCad/
├── libraries/                 # wspólne symbole, footprinty (.kicad_sym, .pretty)
├── Projects
└── README.md
```

Nowy projekt dodajesz jako folder z plikami `*.kicad_pro`, `*.kicad_sch`, `*.kicad_pcb`.
